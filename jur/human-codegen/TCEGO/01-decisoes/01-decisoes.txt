## 1. Busca principal (query)

Campo único, `placeholder="Pesquisa"`, **sem `name` e sem `id`** (Ant Design `Sender` +
react-hook-form). Não há `<form>` na página (`form count = 0`).

```html
<input placeholder="Pesquisa" class="ant-input css-142senq" type="text" value="">
```

Botão de disparo: `button.ant-sender-actions-btn.ant-btn-primary` (circular, sem texto).

⚠️ **`Enter` NÃO dispara a busca** e `page.fill()` não alimenta o estado do react-hook-form —
o POST sai com corpo `{}` (termo perdido) mesmo com o valor visível no input. Isto é
armadilha de mapeamento, não do crawler: o crawler fala com a API.

Contrato real (medido no Network e reproduzido fora do browser):

```
POST https://iago-search-api.tce.go.gov.br/decisions/search?<filtros>
Content-Type: application/json
Body: {"term":"<termo>"}
```

Termo vazio (`{"term":""}`) é aceito e devolve o acervo. Prints: `01.01`, `01.02`, `01.03`.

### 🔴 Ressalvas medidas nos filtros

- 🔴 **`session` exige o ACENTO, e sem ele zera em silêncio.**
  `session=Extraordinária` → **29**; `session=Extraordinaria` → **0** (HTTP 200).
  São filtros de *keyword* exato do Elasticsearch, sem normalização. Vale para
  `type`, `collegiate`, `reporter`, `rapporteur` também: `Resolução`, `Primeira Camara`
  (esta **sem** acento em "Camara", como está na base), `CARLA CINTIA SANTILLO`.
  **Use sempre o rótulo literal devolvido por `/decisions/aggregations`.**
- 🔴 **A janela de data só funciona FECHADA — cada ponta sozinha é IGNORADA.**
  `start=2024-01-01&end=2024-01-31` → **287**. `start=2024-01-01` sozinho → 10.000
  (= acervo saturado). `end=2024-01-31` sozinho → 10.000. `start=2024-01-01&end=2024-12-31`
  → **4.987** (= o ano inteiro, confere com `year=2024`).
  É o par assimétrico do TCE-PR de novo, agora com **as duas** pontas ignoradas.
- 🔴 **Data de filtro é ISO, data de resultado é BR.** O filtro exige `YYYY-MM-DD`
  (`01/01/2024` → **HTTP 500**), mas o campo `date` do card volta `28/10/2024 08:00`.
- ⚠️ **83% do acervo não tem colegiado nem tipo de sessão.** Somando os agregados:
  `ano` = 383.075 e `tipo_documento` = 383.075, mas `colegiado` = **64.797** e
  `tipo_sessao` = **64.797**. Filtrar por colegiado **exclui 318.278 documentos em
  silêncio** — não é "não há julgado", é campo vazio.

## 21. 🔴 O `totalElements` É FABRICADO — a ressalva nº 1 do crawler

`totalElements` **não é a contagem de resultados**. Medido paginando o acervo inteiro
(`term:""`, `size=2000`):

| Requisição | `totalElements` | itens |
|---|---|---|
| `page=0&size=25` | **10.000** | 25 |
| `page=399&size=25` | **10.000** | 25 |
| `page=400&size=25` | **10.025** | 25 |
| `page=401&size=25` | **10.050** | 25 |
| `page=5&size=2000` | **12.000** | 2.000 |
| `page=50&size=2000` | **102.000** | 2.000 |
| `page=190&size=2000` | **382.000** | 2.000 |
| **`page=191&size=2000`** | **383.075** ← o número verdadeiro | **1.075** (última página com dados) |
| `page=200&size=2000` | **10.000** de novo | **0** |

Ou seja `totalElements ≈ max(10.000, min(383.075, (page+1) × size))`. É o
`track_total_hits: 10000` do Elasticsearch vazando como se fosse total.

**Regras que saem daí, e o crawler tem de obedecer:**
1. `totalElements < 10.000` → **valor exato** (confere com o agregado: `year=2024` → 4.987
   na busca **e** 4.987 no agregado `ano`).
2. `totalElements == 10.000` → **saturado**: significa "≥ 10.000, quantidade desconhecida".
   Reportar "10.000 resultados" é afirmação falsa.
3. `totalElements > 10.000` → **artefato do próprio offset**, não é contagem de nada.
4. 🟢 **A saída existe:** `/decisions/aggregations` devolve contagens **exatas** mesmo
   acima do teto (soma de `ano` = soma de `tipo_documento` = 383.075). Quando saturar,
   **conte pelo agregado.**

✅ **Não há teto de profundidade.** Diferente do `index.max_result_window` clássico, a API
paginou até o fim do acervo (383.075 documentos em 192 páginas de 2.000) sem erro.

Default:              size=25   (o SPA usa 25)
Máximo aceito:        size=2000 — pedir 5000 ou 10000 devolve size=2000, SEM erro (trunca em silêncio)
Ao estourar a última: HTTP 200, content=[], numberOfElements=0
Profundidade:         sem teto — page=191&size=2000 chega ao fim do acervo
Total exposto:        SATURADO em 10.000, ver §21

✅ **Estabilidade medida:** `page=3&size=25` rodada **3 vezes** devolveu a **mesma
