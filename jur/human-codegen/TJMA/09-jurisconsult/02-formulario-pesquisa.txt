## 1. Busca principal (query) — "Chave de busca"
------------------------------------------------------------------

Campo de texto livre. Sem limite de caracteres declarado (`maxlength` ausente).
O que ele significa depende do combo "Pesquisar pelo(a)" (§13) e o modo de
combinação dos termos depende do combo "Condição" (§2).

HTML do elemento (DOM depois do AJAX):

  <input class="text-input text-input-md" dir="auto" type="text"
         aria-labelledby="lbl-27" autocomplete="off" autocorrect="off"
         placeholder="" formcontrolname="chave">

Parâmetro na API: `chave`
Obrigatório: sim (o botão "Consultar" fica `disabled` sem ele).

## 2. Operadores — combo "Condição"
------------------------------------------------------------------

O TJMA **não usa operadores textuais** (`E`/`OU`/`NÃO`/`ADJ`/`PROX`/`$`)
digitados dentro da caixa de busca. Ele usa um COMBO chamado "Condição", que
se aplica ao conjunto inteiro dos termos digitados.

HTML do elemento (DOM depois do AJAX):

  <select formcontrolname="condicao" class="ng-untouched ng-pristine ng-valid">
    <option value="0: Object">E</option>
    <option value="1: Object">OU</option>
    <option value="2: Object">Termo único</option>
  </select>

Valores enviados à API (hardcoded no bundle `build/5.js`, método `getConditions`):

  [{idCondicao:"1", strCondicao:"E"},
   {idCondicao:"2", strCondicao:"OU"},
   {idCondicao:"3", strCondicao:"Termo único"}]

Parâmetro na API: `condicao` (1 | 2 | 3). Default do formulário: 3 ("Termo único").

Tabela de operadores do MODELO-TRIBUNAL, preenchida com o que foi possível
verificar. **Nenhuma linha pôde ser testada por contagem**, porque toda busca
é barrada pelo captcha (§15) — está registrado como NÃO TESTADO, não como
"funciona".

| Operador        | Existe? | Como                                   | Testado por contagem? |
|-----------------|---------|----------------------------------------|-----------------------|
| E               | sim     | combo Condição = "E" (`condicao=1`)    | NÃO — busca barrada   |
| OU              | sim     | combo Condição = "OU" (`condicao=2`)   | NÃO — busca barrada   |
| NÃO             | NÃO EXISTE — não há opção de negação em nenhum relatório       | —          |
| ADJ (adjacência)| NÃO EXISTE                                                      | —          |
| PROX            | NÃO EXISTE                                                      | —          |
| $ (radical)     | NÃO EXISTE                                                      | —          |
| "frase exata"   | sim, mas NÃO por aspas: é o checkbox "Frase Exata"             | NÃO — busca barrada   |
|                 | (`fraseExata`), e ele só aparece nos relatórios 2, 4, 5, 6 e 7 |            |
|                 | — o relatório 1 (Acórdãos) NÃO tem "Frase Exata"; nele o       |            |
|                 | equivalente é Condição = "Termo único".                        |            |

⚠️ Ressalva de mapeamento: como não há operador digitável, colocar `E`, `OU`
ou aspas dentro da "Chave de busca" quase certamente vira palavra literal —
mas isso NÃO foi confirmado empiricamente, pela mesma razão.

## 3. Número máximo de páginas / resultados (`max-pages`)
------------------------------------------------------------------

A paginação é por FAIXA de registros, não por número de página:
`inicioPagina` e `fimPagina` (1-based, inclusivos).

  - Desktop ("core"): a tela pede `inicioPagina=1&fimPagina=20` → 20 por página.
  - Mobile: rota `/infinito`, scroll infinito, mesma faixa.
  - Total de resultados: vem no PRÓPRIO registro, campo `int_count` do
    primeiro item (`response.processos[0].int_count`) — não há um campo
    `total` separado.

Teto técnico da base: não observável (busca barrada).

## 4. Filtro de data — JULGAMENTO
------------------------------------------------------------------

**NÃO EXISTE.** O JurisConsult só filtra por data de PUBLICAÇÃO (§5).
Isso vale para os 6 relatórios pesquisáveis. É uma limitação real do módulo
e precisa entrar em qualquer citação: "período" no TJMA = período de
publicação, nunca de julgamento.

------------------------------------------------------------------
## 5. Filtro de data — PUBLICAÇÃO
------------------------------------------------------------------

Dois campos de data (`flatpickr`), exibidos em DD/MM/YYYY.

HTML dos elementos (DOM depois do AJAX):

  <input class="ng2-flatpickr-input flatpickr-input" data-input=""
         type="text" placeholder="xx/xx/xxxx">   <!-- Data Início Publicação -->
  <input class="ng2-flatpickr-input flatpickr-input" data-input=""
         type="text" placeholder="xx/xx/xxxx">   <!-- Data Final Publicação -->

Conversão feita pelo próprio front (bundle `build/5.js`, `setDateInicio`/`setDateFinal`):
DD/MM/YYYY digitado → **YYYY-MM-DD** enviado à API.

Parâmetros na API: `dtaInicio`, `dtaFim` (formato `YYYY-MM-DD`).

Default do formulário: início = 02/01/2020, fim = data de hoje.
Intervalo aberto: sim — há botões de limpar cada data (`clearDateInicio`,
`clearDateFim`), e `prepareGetParams` omite parâmetro vazio da querystring.

⚠️ Os campos de data só são ENVIADOS quando a busca avançada está ligada
(`checkForm=1`). Com `checkForm=0` o front manda `dtaInicio`/`dtaFim` como
`null` e eles somem da querystring — ou seja, **o filtro de data depende do
checkbox de busca avançada**.

Prints: 01.09-calendario-datas-inicio-final-publicacao.png
        02.01-formulario-acordaos.png

## 14. Número do processo — o que alimenta o Checker
------------------------------------------------------------------

Existe, mas **não como consulta separada**: é a mesma busca, com
"Pesquisar pelo(a)" = "Número(s) do Processo" (`tipoPesquisa=6`), disponível
em TODOS os 6 relatórios pesquisáveis. O plural ("Número(s)") indica que
aceita mais de um número.

Formato aceito: não foi possível confirmar (com ou sem máscara CNJ), porque
a busca é barrada pelo captcha.

⚠️ CONSEQUÊNCIA DIRETA: **o Checker do TJMA não pode usar o JurisConsult.**
Ele usa a API Pública do DataJud/CNJ (`api_publica_tjma`), que é oficial,
aberta e cobre TJMA em G1 e G2 — ver §16.3.

  Header: Authorization: APIKey <chave pública do CNJ>
  Body:   {"size":1,"query":{"match":{"numeroProcesso":"<20 dígitos>"}}}

## 17. Sessão e estado
------------------------------------------------------------------

Não há sessão nem cookie de estado para a busca pública. Cada busca carrega
o seu próprio par (captcha de imagem + token do reCAPTCHA). O front guarda os
filtros em `navParams` ao trocar de página da SPA e REUTILIZA o mesmo
`tokenG` ao paginar (visto em `getPaginationResult` → `getJurisprudencias`),
o que sugere que o backend não invalida o token do Google entre páginas.

Existe uma tela de login (`#/login`), com credenciais do sistema SENTINELA —
uso interno do TJMA, indisponível para consulta pública. Usuário logado pula
os dois captchas (`loggedUser ? token=authToken : token=captcha+recaptcha`).

  - clicar no item abre `CaptchaFormPage` → mais um captcha para ver a capa
    do processo (`SgPublicSearchProcessSheetPage`).

Isto é inferência de código, não observação de tela — está registrado como
pendência em `04-bloqueio-captcha.txt`.

------------------------------------------------------------------
## 19. Inteiro teor (download)
------------------------------------------------------------------

Não há endpoint separado de download. O inteiro teor é aberto num modal
(`ModalJurisprudenceInteiroTeorPage`) alimentado pelo objeto que já veio no
payload da busca. Ou seja: **o download não é um bloqueio adicional — ele
está atrás do mesmo portão da busca.** Se a busca passasse, o inteiro teor
viria junto.

------------------------------------------------------------------
## 20. Paginação
------------------------------------------------------------------

Resultados por página:      20 (desktop)
Parâmetro de página:        `inicioPagina` / `fimPagina` (faixa 1-based)
Total exposto?              sim, em `response.processos[0].int_count`
"Ir para página"?           sim, componente `paginationService.getPager()`
Rota alternativa:           `<rota>/infinito` (scroll infinito, mobile),
                            com `time` + `validation` (md5 com salt fixo)

Nada disso pôde ser exercitado: a primeira página nunca foi obtida.
