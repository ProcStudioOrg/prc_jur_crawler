## §0 — O QUE NÃO SE HERDA DOS TRÊS IRMÃOS

| Host | `esaj.` | `esaj.` | `consultasaj.` | **`www2.`** (`esaj.tjal` = NXDOMAIN) |
| Resultados por página | 100 | 20 | 10 | **20** |
| Acento na query | **exige** | normaliza | normaliza | **normaliza** |
| `$` (radical) | 4 | 0 | 0 | **2** (degenera, não zera) |

| Abre a citação por | — | `Relator (a)` | classe processual | **`Número do Processo:`** |
| Estado da base | viva | viva | 🔴 **parada jan/2025** | ✅ **corrente (jul/2026)** |

- `dados.buscaInteiroTeor` (id `iddados.buscaInteiroTeor`) — busca **no inteiro teor**

Medido com `dano moral`: ementa = **103.280**, inteiroTeor = **144.628**.

```html
<input type="text" name="dados.buscaEmenta" id="iddados.buscaEmenta" ...>

Botões da tela: `E`, `OU`, `NÃO` (rótulo com til, valor sem), `ASP` (aspas).

Medido em 05/08/2026, `dano`/`moral` na ementa, 2º grau, acórdãos:

```

dano NAO moral            10.900   ✅ 103.280 + 10.900 = 114.180 EXATO

## §6 — Combos-árvore: classe, assunto, seção

⚠️ **PENDÊNCIA DECLARADA — não enumerados** (mesma pendência do TJAC e do TJAM).

Existem no formulário como par hidden + campo de texto:

```html
<input type="hidden" name="classesTreeSelection.values"  id="classes">
<input type="text"   name="classesTreeSelection.text"    id="classes_selectionText">
<input type="hidden" name="assuntosTreeSelection.values" id="assuntos">

<input type="hidden" name="secoesTreeSelection.values"   id="secoes">
<input type="text"   name="secoesTreeSelection.text"     id="secoes_selectionText">
```

**A página tem ZERO elementos `<select>`** (medido; ver `01-selects.json`, que
está vazio de propósito). Os três "combos" são popups do SAJ que gravam nos
hiddens — não dá para enumerá-los lendo `<option>`. O crawler não expõe flags
para eles: **é lacuna de recurso, não bug**. Não escreva que o TJAL não tem
esses filtros; ele tem, não foram listados.

## §9 — Datas

Quatro campos, dois pares independentes:

```html
<input type="text" name="dados.dtJulgamentoInicio"  id="iddados.dtJulgamentoInicio">
<input type="text" name="dados.dtJulgamentoFim"     id="iddados.dtJulgamentoFim">
<input type="text" name="dados.dtPublicacaoInicio"  id="iddados.dtPublicacaoInicio">
<input type="text" name="dados.dtPublicacaoFim"     id="iddados.dtPublicacaoFim">
```

✅ **Os dois pares são confiáveis aqui** — julgamento e publicação batem em 2024
(28.016 × 27.924). **Não há data-sentinela**: 2004 inteiro = 0, `01/06/2004` = 0,
2010 = 0. Isso é o oposto do TJAM, onde 481 julgados carregavam `01/06/2004` e
37% das publicações recentes caíam nesse balde. Aqui `-di/-df` pode ser usado.

⚠️ **Teto de 1 ano de CALENDÁRIO** (não de dias corridos). Provado por dois
intervalos de 366 dias com respostas opostas:

```
01/03/2023 → 29/02/2024  (366 dias) -> 13.594  ✅ aceita
15/06/2023 → 15/06/2024  (366 dias) ->      0  ❌ recusada
15/06/2025 → 14/06/2026  (364 dias) -> 26.039  ✅ aceita
15/06/2025 → 15/06/2026  (365 dias) ->      0  ❌ recusada
01/01/2025 → 01/01/2026             ->      0  ❌ recusada
02/01/2025 → 01/01/2026             -> 26.504  ✅ aceita
```

Regra: `fim <= início + 1 ano − 1 dia`. Acima disso a tela avisa ("A faixa entre
data de inicio e data de fim deve ser de no máximo 1 ano") mas responde **HTTP
200 com o formulário de volta** — um crawler que só conta cards lê 0. O
`TJALCrawler` distingue recusa de zero genuíno e fatia sozinho.

## §13 — Passo 0: API pública — **NÃO EXISTE**, e o portal mente com 200

Procurado em 05/08/2026:

```
dadosabertos.tjal.jus.br  -> 45.169.162.16, 302 → https://tjal.jus.br/enderecos
                             (página de endereços do portal, não dados abertos)
api.tjal.jus.br           -> 172.17.35.106 — IP PRIVADO (RFC1918), não responde
                             de fora. Vazamento de DNS interno, não API pública.
jurisprudencia.tjal...    -> NXDOMAIN
esaj.tjal.jus.br          -> NXDOMAIN  (⚠️ o host do e-SAJ aqui é `www2`)
```

⚠️ **ARMADILHA: todo path inventado responde HTTP 200.** Medido, com md5:

```
tjal.jus.br/dados-abertos            200  md5 f47ba538d050  1730 bytes
tjal.jus.br/swagger                  200  md5 f47ba538d050  1730 bytes
tjal.jus.br/openapi.json             200  md5 f47ba538d050  1730 bytes
tjal.jus.br/api/  /rest/  /v1/       200  md5 f47ba538d050  1730 bytes
tjal.jus.br/qualquer-coisa-inventada-9z  200  md5 f47ba538d050  ← A PROVA
www2.tjal.jus.br/<qualquer coisa>    200  md5 9ab136c8168f  5705 bytes
```

O md5 é **idêntico ao da home** em todos os casos: é a shell do SPA (Vite) em
`tjal.jus.br` e uma página fixa em `www2`. É a armadilha do TJAC (vhost curinga)
em forma mais perigosa, porque aqui o path inventado também passa.
**Confira o md5 antes de comemorar um 200.**

**DataJud (CNJ)** continua sendo a única API pública possível para este tribunal,
e só serve ao Checker (não tem ementa nem inteiro teor). O `TJALChecker` não
precisa dele: o próprio `dados.nuProcOrigem` responde por número.
