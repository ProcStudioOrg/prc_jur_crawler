### Estrutura
```html

  <li class="page-item active"><a class="page-link" start="0" rows="20">1</a></li>
  <li><a class="page-link" start="20" rows="20">2</a></li>
```

### Seletores
- Pagina ativa: li.page-item.active a.page-link
- Proxima pagina: li:not(.active) a.page-link (start > current)
- Atributos: start (offset), rows (items per page - sempre 20)

### Navegacao
Para navegar: atualizar parametro `start` na URL ou clicar no link
- Pagina 1: start=0
- Pagina 2: start=20
- Pagina 3: start=40
- Formula: start = (pagina - 1) * 20

### 4. extractResults()
```javascript
const results = [];
const panels = await page.locator('.panel.panel-default').all();

for (const panel of panels) {
  const result = await panel.evaluate(el => {
    const getValorCampo = (campo) => {
      const rows = el.querySelectorAll('table tr');
      for (const row of rows) {
        const cells = row.querySelectorAll('td');
        if (cells[0]?.textContent?.trim() === campo) {
          return cells[1]?.textContent?.trim() || '';
        }
      }
      return '';
    };

    const ementaBtn = el.querySelector('button.item_button[data-id]');
    const uuid = ementaBtn?.getAttribute('data-id') || '';
    const numeroProcessoEl = el.querySelector('.label-processo');
    const numeroProcesso = numeroProcessoEl?.textContent?.trim() || '';
    const inteiroTeorLink = el.querySelector('a[href*="documento.php"]')?.href || '';
    const processoLink = el.querySelector('a[href*="eproc"]')?.href || '';
    const ementa = el.querySelector('.content_ementa')?.innerHTML || '';

    return {
      uuid,
      numeroProcesso,
      classe: getValorCampo('Classe'),
      assuntos: getValorCampo('Assunto(s)'),
      competencia: getValorCampo('Competencia'),
      relator: getValorCampo('Relator Originario'),
      dataAutuacao: getValorCampo('Data Autuacao'),
      dataJulgamento: getValorCampo('Data Julgamento'),
      ementa: ementa.substring(0, 15000),
      inteiroTeorLink,
      processoLink
    };
  });

  if (result.numeroProcesso) {
    results.push(result);
  }
}

return results;
```

### 5. hasNextPage()
```javascript
const pagination = page.locator('.pagination');
const activeItem = pagination.locator('li.page-item.active');
const allItems = await pagination.locator('li').all();
const activeIndex = await activeItem.evaluate(el => {
  const parent = el.parentElement;
  return Array.from(parent.children).indexOf(el);
});
return activeIndex < allItems.length - 1;
```

### 6. goToNextPage()
```javascript
// Obter start atual
const activeLink = page.locator('li.page-item.active a.page-link');
const currentStart = parseInt(await activeLink.getAttribute('start') || '0');
const nextStart = currentStart + 20;

// Clicar no link da proxima pagina
await page.click(`a.page-link[start="${nextStart}"]`);
await page.waitForLoadState('networkidle');
await page.waitForTimeout(1000);
```

## Notas Importantes

1. O site usa Bootstrap 5 para interface
2. Os IDs de checkboxes de filtro sao dinamicos (contem hash)
3. Use o atributo `name` para identificar checkboxes de forma confiavel
4. Os filtros de Relator, Classe, etc. sao carregados via AJAX
5. Cada pagina tem 20 resultados fixos
6. A ementa e exibida inline no card (nao precisa abrir modal)
7. O botao "Ementa" abre um modal, mas o conteudo ja esta em div.content_ementa
8. Paginacao usa atributos `start` e `rows` nos links
9. Para busca direta, use: https://juris.trf2.jus.br/consulta.php?q={termo}
10. Os numeros de processo tem formato: NNNNNNN-NN.NNNN.N.NN.NNNN
