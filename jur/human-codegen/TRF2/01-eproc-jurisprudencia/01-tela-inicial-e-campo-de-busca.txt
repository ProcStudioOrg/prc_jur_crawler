## 1. Busca principal (query)

Campo único de texto livre. Não há limite de caracteres declarado.

    id/name: txtPesquisa      type=search      placeholder="Informe o texto para pesquisa"

HTML (do DOM depois do AJAX):

    <input type="search" id="txtPesquisa" name="txtPesquisa" class="form-control campoPesquisa"
           value="" placeholder="Informe o texto para pesquisa" aria-label="Texto para pesquisa"
           aria-describedby="btnConsultar" style="padding-right: 2rem">

O botão de submit tem id duplicado na página: `#btnConsultar_form_inicial` (visível, o da
tela inicial) e `#btnConsultar` (dentro do painel avançado, invisível até abrir). Um
`click()` cego em `#btnConsultar` fica pendurado — use o primeiro visível.

⚠️ **O comportamento default NÃO é "E implícito"** — é o defeito descrito em §7. Leia lá
antes de montar qualquer query.

Campos irmãos, todos na mesma tela (o painel "Pesquisa avançada" começa colapsado,
`#divPesquisaAvancada.collapse`; sem abrir, os filtros não são enviados pelo formulário):

| Campo                      | id / name                | Default    | O que faz |
|----------------------------|--------------------------|------------|-----------|
| Origem                     | `selOrigem[]`            | TRF2 (1)   | §2 — a desambiguação |
| Tipo de documento          | `selTipoDocumento[]`     | (nenhum)   | §3 |
| Classe                     | `selClasse[]`            | (nenhum)   | §3 |
| Relator                    | `selRelator[]`           | (nenhum)   | §3 |
| Órgão julgador             | `selOrgao[]`             | (nenhum)   | §3 |
| Precedentes relevantes     | `chkPrecedenteRelevante` | desmarcado | só jurisprudência selecionada |
| Agrupar Resultados         | `chkAgruparResultados`   | **marcado**| agrupa documentos do mesmo processo |
| Pesquisar em: Inteiro teor | `rdoCampo=I`             | **marcado**| escopo default |
