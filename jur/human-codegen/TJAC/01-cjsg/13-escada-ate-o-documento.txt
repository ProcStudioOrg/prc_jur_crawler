## Resumo em uma linha

**Ementa sim, íntegra, de graça, já no payload da busca. Inteiro teor não,
reCAPTCHA.**

### ⚠️ A sessão da busca NÃO destrava

Testado nos dois cenários, em 3 documentos diferentes (2509158, 2509146, 2509126):

```
sem cookie                    -> HTTP 200, text/html, 10.702 B, captcha
COM o JSESSIONID da busca     -> HTTP 200, text/html, 10.657 B, captcha
```

Não é sessão. É captcha. Este repo não automatiza captcha.

### A chave é composta

`cdAcordao` **e** `cdForo`. Os dois vêm como atributos do `<a>` no card. No TJAC
o `cdForo` medido foi `0` em todos os cards, mas é enviado assim mesmo — o
formulário do captcha o carrega como hidden, o que confirma que faz parte da
chave e não é decorativo.

## Degrau 4 — não existem

Não há botão "copiar citação", "consulta processual do processo",
"compartilhar" nem "documento original em outro formato". A citação oficial vem
como texto dentro do `textAreaDados` (ver `10-resultados.txt` §2).

## O que o crawler faz com isso

`--fetch-inteiro-teor` no TJAC **não baixa PDF**. Grava um `.txt` por julgado com:

- metadados completos (processo, cdAcordao, classe, assunto, órgão, comarca,
  relator, as duas datas);
- a **citação oficial**;
- uma linha dizendo que **não existe permalink** e qual é a URL bloqueada;
- a instrução de verificação por reconsulta (`./bin/jur tjac -n <nº>`);
- a **EMENTA ÍNTEGRA**, rotulada como ementa;
- um bloco `=== INTEIRO TEOR ===` dizendo explicitamente **NÃO DISPONÍVEL** e
  por quê.

A alternativa — tentar o `getArquivo.do` e gravar o que voltar — gravaria 10 KB
de HTML de captcha num arquivo com nome de acórdão. É exatamente o erro que a
invariante nº 1 do repo proíbe.

`--tentar-pdf` força uma tentativa real por documento. Serve para **reconferir
se o bloqueio caiu**; se algum PDF vier, o crawler grita
("🎉 … o reCAPTCHA do TJAC pode ter caído") e o `CLAUDE-TJAC.md` precisa ser
revisto.

## Reteste — o que medir quando alguém perguntar "ainda está travado?"

```bash
curl -s -o /tmp/tjac-it.bin -w "%{http_code} %{content_type} %{size_download}\n" \
  "https://esaj.tjac.jus.br/cjsg/getArquivo.do?cdAcordao=2509158&cdForo=0"
head -c5 /tmp/tjac-it.bin    # "%PDF-" = destravou; "<!DOC"/"<html" = ainda travado
```

Ou, pelo repo: `node src/TJACTestes.js` — o teste 8 mede exatamente isso e passa
tanto se o bloqueio persistir (esperado) quanto se cair (e avisa).
