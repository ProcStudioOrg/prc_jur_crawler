## §0 — O QUE NÃO SE HERDA DO TJMS

O formulário é byte a byte o mesmo molde do e-SAJ. **Quatro coisas mudam**, e
todas foram medidas hoje. Copiar as suposições do TJMS produz bug silencioso:

| | TJMS | **TJAC** |
|---|---|---|
| Resultados por página | 100 | **20** |
| Acento na query | **muda tudo** (usucapiao=3 × usucapião=3.885) | **não muda nada** (334 × 334) |
| Abas de tipo | A, H, D | **só A e D** (não existe "Homologação de Acordo") |
| Paginação | instável (~1 em 100 pulado) | **estável** (3/3 idênticas) |
| `trocaDePagina.do` sem sessão | HTTP 200 com zero cards (bug silencioso) | **HTTP 404** (falha barulhenta) |
| Inteiro teor (PDF) | livre, com rate limit | **atrás de reCAPTCHA** (§14) |
| Rodapé de citação | `(TJMS. Classe n. …)` | `(Relator (a): …; Comarca: …)`, sem sigla |
| Teto de 1 ano na data | zero **mudo** | zero **com aviso na tela** |

⚠️ **A armadilha do DNS curinga.** Os três subdomínios "promissores"
(`dadosabertos`, `api`, `jurisprudencia`) **resolvem** e respondem **HTTP 200**.
Parece dados abertos; não é. Todos servem o **mesmo HTML da home do portal** —
provado por md5 idêntico ao de `www.tjac.jus.br`:

```
jurisprudencia.tjac.jus.br  -> 3ef4ac90ee77235fa13dacdc3a84c1d1
dadosabertos.tjac.jus.br    -> 3ef4ac90ee77235fa13dacdc3a84c1d1
api.tjac.jus.br             -> 3ef4ac90ee77235fa13dacdc3a84c1d1
www.tjac.jus.br             -> 3ef4ac90ee77235fa13dacdc3a84c1d1
```

É um vhost curinga. **DNS que resolve ≠ serviço que existe**, e 200 com o
tamanho da home é o sinal. Quem parar no `getent hosts` conclui que o TJAC tem
API de jurisprudência e escreve um crawler contra uma página institucional.

Conclusão: **não existe API oficial de jurisprudência do TJAC.** Não é "não
procurei" — está medido acima. O acesso do crawler é `http` (POST direto no
cjsg, sem browser).

O portal oficial, por sua vez, **linka o cjsg**: `www.tjac.jus.br/jurisprudencia/`
traz `https://esaj.tjac.jus.br/cjsg/resultadoCompleta.do`. A porta está certa.

tipos A+D, sem termo → 0 cards, 69.159 bytes). Não existe "listar tudo".

### 1b. ✅ ACENTO NÃO IMPORTA AQUI — e é o oposto do TJMS

O índice do TJAC **normaliza acentuação**. Três pares medidos no mesmo campo
`dados.buscaEmenta`, 2º grau, acórdãos:

```
usucapiao    ->    334   |  usucapião     ->    334
execucao     -> 11.078   |  execução      -> 11.078
prisao       ->  7.949   |  prisão        ->  7.949
alimenticia  ->    130   |  alimentícia   ->    130
```

Contagem **idêntica** nos quatro pares ⇒ o backend normaliza. **Não avise o
usuário sobre acento neste tribunal** — seria mandá-lo refazer uma busca que já
estava certa, e a suspeita erraria o diagnóstico do zero verdadeiro.

Isto é o inverso exato do TJMS (3 × 3.885). **A ressalva é por instalação, não
por família de sistema.** Meça antes de copiar.

## 2. Operadores — testados um a um, não presumidos

A tela oferece quatro botões que inserem operadores no campo: `E`, `OU`, `NÃO`,
`" "` (aspas). Testado com `dano`/`moral` em `dados.buscaEmenta`, 2º grau,
acórdãos (`dano` sozinho = 10.907):

| Operador | Funciona? | Medição | Observação |
|---|---|---|---|
| (espaço) | sim, é **E implícito** | `dano moral` → 7.649 | idêntico a `dano E moral` |
| `E` | **sim** | `dano E moral` → 7.649 | conjunção |
| `OU` | **sim** | `dano OU moral` → 11.163 | maior que E, como esperado |
| `NAO` (sem acento) | **sim** | `dano NAO moral` → 3.258 | exclusão |
| `NÃO` (com acento) | **NÃO é operador** | `dano NÃO moral` → 6.429 | vira termo literal |
| `"frase exata"` | **sim** | `"dano moral"` → 7.149 | menor que o E implícito |
| `$` (radical) | **NÃO** | `usucapi$` → **0** | zera a busca |
| `ADJ` | **NÃO** | `dano ADJ2 moral` → **0** | vira texto literal e zera |
| `PROX` | **NÃO** | `dano PROX5 moral` → **0** | vira texto literal e zera |

**Prova aritmética de que `NAO` é o operador e `NÃO` não é:**

```
dano                 = 10.907
dano moral           =  7.649   (E implícito)
dano NAO moral       =  3.258   = 10.907 - 7.649  ✅ é a diferença exata
dano NÃO moral       =  6.429   ✗ não bate com nada; é "dano E não E moral"
```

⚠️ **Três formas de zerar a busca sem erro neste portal**: `ADJ`, `PROX` e `$`.
O `$` é a diferença contra o TJMS, onde ele ao menos devolvia algo (4). O
`TJACCrawler.avisarOperadores()` alerta nos três casos.

```html
<input type="button" name="E"   value=" E "  >
<input type="button" name="OU"  value=" OU " >
<input type="button" name="NAO" value=" NÃO ">
<input type="button" name="ASP" value="&quot;&nbsp;&nbsp;&quot;">
```

### 4b. ⚠️ TETO DE 1 ANO — acima disso, zero (mas COM aviso na tela)

O intervalo aceito é de no máximo **365 dias corridos**, ou seja **364 dias de
diferença** entre início e fim. Um dia a mais e a resposta é **0**:

```
01/01/2025 -> 31/12/2025  (364 de diferença) -> 1.804
01/01/2025 -> 01/01/2026  (365 de diferença) ->     0
01/01/2025 -> 02/01/2026  (366 de diferença) ->     0
04/08/2025 -> 04/08/2026  (365 de diferença) ->     0
01/01/2020 -> 31/12/2025  (6 anos)           ->     0
```

Vale **igual** para a data de publicação (medido: `04/08/2025`–`04/08/2026` por
publicação → 0).

⚠️ **Diferença contra o TJMS:** aqui a tela **avisa**. A resposta traz o texto

```
Atenção — A faixa entre data de inicio e data de fim deve ser de no máximo 1 ano.
```

Mas o **HTTP continua 200** e o corpo é o **formulário de consulta de volta**,
não o resultado. Um crawler que só conta cards lê 0 do mesmo jeito.

**O sinal técnico para distinguir os dois casos** (e o `TJACNavigator` usa este):

```
estouro de 1 ano  -> NENHUM hidden totalResultadoAba-*   (totais = {})   69.183 B
zero genuíno      -> totalResultadoAba-A = 0             (totais = {A:0}) 68.970 B
```

O `TJACCrawler` fatia o intervalo em janelas de 364 dias, junta e deduplica por
`cdAcordao` — e avisa, porque aí `-m N` passa a valer **por janela**.
Medido: `01/01/2024`–`04/08/2026` vira 3 janelas (968 + 1.819 + 1.025).

## 15. Encoding

`Content-Type: text/html;charset=UTF-8` — na tela **e** nas respostas. É incomum:
o e-SAJ clássico costuma ser ISO-8859-1 (o e-Proc do próprio TJAC responde em
ISO-8859-1). O corpo do POST vai em **UTF-8** e o servidor aceita.

O HTML usa entidades nomeadas antigas dentro do bloco de ementa sem formatação.
Além das do TJMS, o TJAC usa **`&sect;`** de verdade ("CPC, arts. 509, &sect; 2º")
— o `TJACNavigator.decodeEntidades` cobre `&sect;`, `&deg;`, `&para;`,
`&laquo;`/`&raquo;`, `&ndash;`/`&mdash;` além das acentuadas.

## 16. Balanceador

O JSESSIONID termina em `.cjsg1` ou `.cjsg2` — há pelo menos dois nós. Ao
contrário do TJMS, **não** foi observada divergência de total entre eles nas
medições de hoje, e a paginação saiu estável. Não foi feito um teste dedicado de
dessincronização entre nós: registrado como **não medido**, não como "não existe".
