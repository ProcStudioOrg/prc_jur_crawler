## 🔴 NÃO EXISTE OPERADOR BOOLEANO. E O ESPAÇO É **OR**.

A aritmética, com `usucapião` = 2.001 e `enfiteuse` = 12:

  usucapião enfiteuse       2.013   = 2.001 + 12  ✓ união exata
  usucapião zzqxwj          2.001   <- termo inexistente NÃO zera (se fosse AND, daria 0)
  enfiteuse usucapião       2.013   <- ordem não importa
  usucapião AND enfiteuse   2.315   <- "and" virou mais um termo do OR
  usucapião ADJ enfiteuse   2.082   <- idem
  usucapião NAO enfiteuse   6.478   <- idem, e INFLA 3×
  usucapião -enfiteuse      2.013   <- o hífen é ignorado
  usucapião E/OU/OR/NOT …  10.000   <- saturam: são palavras comuníssimas
  "dano moral" (com aspas) 10.000   <- = sem aspas; aspas não delimitam frase
  usucapi*                  1.727   = usucapi (1.727) <- o `*` é ignorado, e nenhum dos
                                       dois alcança `usucapião` — não há busca por prefixo

🔴 **Todos os "operadores" INFLAM em vez de restringir**, e inflar não dá sintoma:
   6.478 se lê como "tema vasto". É o oposto do zero silencioso e igualmente caro.

✅ **`match_phrase` é a única forma de exigir os termos juntos — e é frase ORDENADA:**
     search       "usucapião extraordinária"  = 6.679  (OR)
     match_phrase "usucapião extraordinária"  =    77  (frase)
     match_phrase "extraordinária usucapião"  =     0  (a ordem importa ⇒ é frase mesmo)
⚠️ `search` e `match_phrase` **se INTERSECTAM**, não se somam:
     search="enfiteuse" + match_phrase="usucapião" = 0

## Busca por número de processo — os DOIS formatos funcionam

  "0001783-98.2002.8.03.0001"  -> 2 documentos  (uma sentença + uma decisão)
  "00017839820028030001"       -> 2 documentos
  número inventado             -> 0
Raro no repo: no TJRO e no TJPE a máscara devolve 0 calado; aqui os dois passam.

🔴 **MAS NÃO É UM CAMPO — É A BUSCA LIVRE, QUE É OR.** Não existe filtro
   `numeroProcesso` nesta base: o número cai no mesmo `search` das palavras. Logo um
   documento que apenas CITA o número entra no resultado (o problema do TJES/TJPI). O
   `TJAPChecker` confere o `Nº Processo` de cada documento devolvido e reporta quantos
   vieram por citação em `deOutroProcesso`.
