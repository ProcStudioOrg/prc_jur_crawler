## Que sistema é

Laravel + Livewire + Alpine.js + Flux — família NOVA no repo (não é SPA-com-REST, não é
JSF, não é Rails, não é PHP+Solr do TJTO). Livewire é server-driven: o estado vai e volta
num snapshot assinado por checksum, via POST /livewire/update.
Scripts: /livewire-53cc04b2/livewire.min.js, /build/assets/app-DteveQ2O.js, /flux/flux.min.js

⚠️ Consequência para o crawler: NÃO há endpoint REST limpo. Reproduzir a busca fora do
   browser exige carregar a página, extrair o snapshot Livewire e reenviá-lo. NÃO foi
   medido se isso funciona por http puro — é a primeira coisa a fazer no próximo slot.
   Arquivo com o XHR capturado: 02-xhr-busca.json

  search          — busca livre (input[type=search])
